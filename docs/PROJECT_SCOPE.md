# MetroMind AI — Academic Project Scope

## Problem
Metro route selection requires balancing distance, estimated travel time, and transfers. The application will compare graph search strategies and present explainable route results.

## Implemented at scaffold stage
Repository organization and planning documentation only.

## Planned core features
- Guest station search and route planning
- User signup/login and authenticated history/favorites
- Graph construction from validated station/edge data
- BFS, Dijkstra, and transfer-aware route comparison
- Route display and reproducible algorithm tests

## Planned stretch features
- AI natural-language route assistant
- Travel analytics and additional metro networks

## Data integrity
Use an attributed and legally reusable Delhi Metro dataset. Record its source, retrieval date, licensing, and coverage. Do not fabricate station connections, travel times, or fares.

## Evaluation
Compare route correctness, runtime, and transfer counts across a reproducible test set. Record actual measured results, not estimates.
